# Support

TimeLex is pre-alpha and maintained part-time. Please use the channel that fits:

| You want to | Go to |
|---|---|
| Ask a question or float an idea | [GitHub Discussions](https://github.com/konethegreat/timelex/discussions) |
| Report a bug or request a feature | [Issues](https://github.com/konethegreat/timelex/issues/new/choose) |
| Challenge a design decision | "Decision proposal" issue, or a PR with an ADR |
| Report a vulnerability | [Private advisory](https://github.com/konethegreat/timelex/security/advisories/new) ([SECURITY.md](SECURITY.md)) |
| Discuss a pilot at your firm | Open a Discussion titled "Pilot"; do not include client information |

No hosted service exists yet, so there is no SLA.
